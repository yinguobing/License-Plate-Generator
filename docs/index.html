功能特性

为什么选择
这个生成器？

不仅仅是随机生成车牌——这是一套完整的面向生产级 LPR 训练的数据增强流水线。

完整字符集

覆盖 31 个省份、24 个英文字母、10 个数字，以及特殊字符（使、领、学、港、澳、警），涵盖 GA 36-2018 标准中所有令牌位置。

自定义规则

可通过自定义字符集、位置、颜色和背景来定义专属车牌格式，不限于中国车牌样式。

批量生成

数秒内生成数千张带标注的图像。每张车牌附带精确的字符标注，完美适配监督学习训练。

数据增强

内置打磨器支持曝光调整、运动模糊、高斯噪声和锐化处理，模拟真实世界的拍摄条件。

像素级合成

带 Alpha 遮罩的字符叠加，每个位置颜色可独立配置。每个字符精确对位，严丝合缝。

纯 Python + OpenCV

零机器学习框架依赖。仅需 Python 3 和 OpenCV 4.5+，随处运行——云端、边缘设备或本地均可。

工作原理

处理流程

从规则定义到训练就绪图像，四个环节一气呵成。

01 / 规则

定义车牌格式

选择内置规则或自行定义每个字符位的字符集、位置与颜色。

02 / 生成

随机组合拼合

随机采样字符，以 Alpha 混合方式精确合成到车牌背景的像素坐标上。

03 / 打磨

做旧与老化

施加可配置的噪声、模糊、曝光偏移与锐化效果，模拟真实拍摄退化过程。

04 / 输出

标注数据集

每张图像导出时携带真实字符标注，可直接接入 LPR 训练流水线。

快速开始

五行代码

几秒钟内生成你的第一张车牌图像。

demo.py 
from core.license_plate import LPImageGenerator
from core.grind import Grinder
from patterns.china import BLUE

# 创建蓝牌生成器
generator = LPImageGenerator(BLUE)
grinder = Grinder()

# 生成并增强
image, label = generator.random_generate()
image = grinder.make_noise(image)
print(f"Generated: {label}")  # → "京A·B1234"
